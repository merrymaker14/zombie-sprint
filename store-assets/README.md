# Zombie Sprint — store materials

Материалы сняты из реального запуска игры на аппаратном GL: меню с зомби-гонщиками
и живые заезды на всех четырёх трассах. Мультяшные зомби, без крови и хоррора.
Комплекты лежат в двух языках: `ru/` и `en/` (надписи в игре и подзаголовок трейлера).

## Комплекты

- `yandex/` — иконка 512×512, обложка 800×470, 4 скриншота геймплея 1920×1080
  (Яндекс требует геймплей не меньше чем на 70% кадра), горизонтальное видео
  `trailer-19s-1280x720.mp4` (обязательное) и вертикальное `trailer-19s-720x1280.mp4`
  (у Яндекса оба до 28 с и до 100 МБ).
- `vkok/` — иконки 576/278/150/32, snippet 1120×630, 6 скриншотов 1200×600,
  трейлер `trailer-27s-1280x720.mp4` (у ВК потолок 30 с).
- `crazy/` — иконка 512×512, обложки 800×800, 800×1200 и 1920×1080, 6 скриншотов
  1920×1080, трейлеры `trailer-19s-1280x720.mp4` и `trailer-19s-720x1280.mp4`
  (у CrazyGames потолок 20 с).
- `gamedist/` — иконка, три thumbnail, marketing-баннеры 1280×720 и 1280×550,
  обложка 1920×1080 и трейлер `trailer-27s-1280x720.mp4`.

Трейлеры смонтированы под доли гоночной темы игры (152 bpm): каждый план кратен доле,
склейки встык, музыка с первой ноты. Реальный геймплей занимает не меньше 70% ролика
(старт и заезды: 75% в 19-секундном, 74% в 27-секундном). Ролики не хранятся в git —
пересобираются.

## Пересборка

```bash
PLAYWRIGHT_FROM="<путь к package.json рядом с playwright>" npm run promo
PROMO_LANG=en npm run promo      # один язык
KEEP_RAW=1 npm run promo         # оставить store-assets/_raw: клипы и раскадровки
```

Нужны ffmpeg и Chromium из Playwright с аппаратной графикой: на программном рендере
игра включает режим экономии, и кадры выйдут мыльными. Раскадровки
`_raw/contact-<язык>-<версия>.png` показывают по кадру из середины каждого плана.
