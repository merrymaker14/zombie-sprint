# Zombie Sprint — store materials

Материалы сняты из реального запуска игры после старта забега. В комплекте нет
крови или хоррора: это яркий семейный arcade-racing стиль.

## Комплекты

- `en/yandex/` — иконка 512×512, обложка 800×470, 4 скриншота 1920×1080,
  trailer 1280×720 и 10-секундная video cover.
- `en/vkok/` — иконки 576/278/150/32, snippet 1120×630, 4 скриншота
  1200×600 и trailer 1280×720.
- `en/crazy/` — иконка 512×512, square 800×800, portrait 800×1200,
  landscape 1920×1080, 4 скриншота, landscape trailer и portrait trailer.
- `en/gamedist/` — иконка, три thumbnail, marketing-баннеры 1280×720 и
  1280×550, landscape cover и trailer 1280×720.

## Пересборка

```bash
npm run promo
```

Скрипт поднимает локальную игру в Chrome, снимает реальные экраны меню и гонки,
оформляет размеры через ffmpeg и проверяет, что материалы сохранились в папках
площадок.
